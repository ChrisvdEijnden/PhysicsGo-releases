# PhysicsGo-releases

PhysicsGo desktop installers. Every version is on the [Releases](https://github.com/ChrisvdEijnden/PhysicsGo-releases/releases) page; the latest one is what the Download button on the PhysicsGo website offers.

The desktop app opens PhysicsGo in a window of its own. The first time, choose **PhysicsGo online**, or **My school runs its own server** and type its address. PhysicsGo also works in the browser without installing anything; sensors over USB or Bluetooth need Chrome or Edge there.

## Which file

| System | File |
| --- | --- |
| Windows | `PhysicsGo_<version>_x64-setup.exe` (or the `.msi` for managed installs) |
| macOS (Apple silicon and Intel) | `PhysicsGo_<version>_universal.dmg` |
| Linux | `.AppImage` (any distribution), `.deb` (Debian, Ubuntu) or `.rpm` (Fedora, openSUSE) |

## What's new in 1.3.0

- **Signing in without choosing who you are.** One box takes an email address or a code. A school has a code for its teachers and one for its administrators; each class has its own 6-digit code, with which new students make their account using only their first name.
- **School administrators** manage their school on the new School page: its codes, its teachers, and every class with its students.
- **Work per class.** A student who gets an assignment in two classes, or again next year, has a separate piece of work and hand-in in each.
- **Reviewing.** A To review list on the dashboard and per class, Next to review, Approve or Return for revision, and optionally how many tries each answer took.
- **Hand-in emails.** An opt-in daily email with the number of new hand-ins per class and assignment, without students' names.
- **Pages keep themselves up to date**, and an assignment published during the lesson opens without a reload.
- **Desktop app:** PhysicsGo online in one click, a server check that works behind a proxy, and links and downloads in the computer's own browser.
